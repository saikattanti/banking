# Security Policy

## Supported Versions

Security updates are prioritized for the latest state of the default branch.

| Version | Supported |
| ------- | --------- |
| main    | ✅ |
| older branches | ❌ |

## Reporting a Vulnerability

Please do **not** disclose security issues publicly.

To report a vulnerability:

1. Create a private security advisory in GitHub for this repository, or
2. Contact the maintainer privately through GitHub.

Include as much detail as possible:

- Affected area/file
- Reproduction steps
- Impact assessment
- Suggested remediation (if available)

You can expect an acknowledgment within 72 hours, followed by triage and remediation planning.
